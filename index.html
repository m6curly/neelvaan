RASTER ANALYSIS

Change detection

Compare two matching GeoTIFF rasters. Processing runs in this browser.

01 · Before image

No file selected

02 · After image

No file selected

03 · Analysis settings

Differences within ± threshold are classed as no significant change. Enter the threshold in the same units as the raster values.

Both rasters must have the same CRS, extent, pixel size, width and height. Align/resample them first in QGIS if they differ. Large GeoTIFFs are read and compared in 128-row tiles; there is no fixed 12-million-pixel or 500 MB upload cap. Cloud and shadow masking must already be applied to both inputs; this tool uses GeoTIFF NoData values only. Browser memory and the classic TIFF 4 GB export format remain practical limits.

Select both rasters to begin.

THERMAL REMOTE SENSING

Land surface temperature

Calculate Landsat 8/9 Collection 2 Level-2 surface temperature from GeoTIFF bands.

01 · Surface temperature band

No file selected

Choose the native Collection 2 Level-2 ST_B10 file with raw DN values. Do not pre-apply its scale factor, or select a true-colour / browse image.

02 · Quality masks

No QA_PIXEL file selected
No ST_QA file selected

QA_PIXEL masks fill, dilated cloud, cirrus, cloud, cloud shadow and snow. ST_QA is read with its 0.01 K scale when supplied. Large scenes are read and processed in 128-row tiles without a fixed pixel-count or 500 MB upload cap; actual limits depend on browser/device memory and available storage.

For a defensible result, upload the matching QA_PIXEL file. Without it, the calculation cannot identify cloud, shadow or snow pixels and the output will be marked unmasked.

Select the ST_B10 raster to begin.
